NWK_GetShortAddr Function

Syntax

ShortAddr_t NWK_GetShortAddr(void);

Description

This function returns a short address allocated by parent.

Input Parameters
  • None
Return Type and Values
  • Short address of this node or NWK_NO_SHORT_ADDR
