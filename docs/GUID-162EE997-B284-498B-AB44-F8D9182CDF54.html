ZDO_WakeUpInd Function

Syntax

void ZDO_WakeUpInd(void);

Description

Sleep timer wake-up indication. The user can call this function after wake-up due to a sleep timer. When the function is entered, the stack is already fully operational.

Input Parameters
  • None
Return Type and Values
  • None
